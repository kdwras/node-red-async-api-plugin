# node-red-async-api-plugin

This project provides a Docker-based environment to run Node-RED
and supporting services for development and testing.

---

## Prerequisites

- Docker
- Docker Compose

---

## Build Docker images

Before running the project for the first time, build the Docker images:

```bash
./build.sh
```
Start the containers

To start the project:

```bash
./start.sh
```
Stop the containers

To stop the running containers:

```bash
./stop.sh
```
Restart the containers

To restart the containers:

```bash
./restart.sh
```
